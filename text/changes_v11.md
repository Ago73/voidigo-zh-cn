# v11 修正（基于实机截图）

1. 换行吞字 / 标点出现在行首
   - 原因：v10 的逐字换行补丁把“断行位置的那个汉字”当成空格处理，运行库会把它替换成行尾结束符，于是每次自动换行都吞掉一个字（新手枪“只要握得稳”丢了“握”，德拉什简介丢了“的/她/清”），避头尾检查也落在被吞的字上，导致“，”出现在行首。
   - 修正：文本里在合法断点插入零宽空格 U+200B（不在避头标点前、不在避尾标点后），运行库只在空格或 U+200B 处断行，被吞掉的只是零宽空格。只处理 16 字以上且不走 $ 高亮渲染器的条目（642 条）。
2. 带 $ 高亮的提示框只显示最后一行
   - 原因：这类提示框按空格切词，原文每行都以“空格+\n”结尾；中文没有空格，整段成了一个词，渲染器只保留 \n 之后的部分。
   - 修正：64 条此类文本在每个 \n 前补空格。
3. 精华提示（四条，营地精华堆与解锁条件共用同一字符串）

   | $fully upgrade$ a powerup | 一局内把一个道具$升满级$，/ 即可解锁它的精华。/ 集齐… |

   | $survive the Void$ | 一局内$在虚空中存活$，/ 即可解锁角色的精华。/ 集齐… |
